# Nancy Matsuda — Product Portfolio

A first functional portfolio built with Next.js and React. Inspired by the editorial structure and playful scrolling experience of the Rohit Menda reference, with original code and content.

## Local preview

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Publish with Vercel (no command line required)

1. Create a free GitHub account at https://github.com/signup.
2. Create a new repository named `nancy-portfolio`.
3. Upload the contents of this folder to the **repository root** (not inside another subfolder) and commit.
4. Go to https://vercel.com/new and sign in with GitHub.
5. Import `nancy-portfolio`. Vercel should detect Next.js automatically. Click **Deploy**.
6. After deployment, open the generated `.vercel.app` link.

## Customize

- Edit `app/page.tsx` for bio, projects, metrics, and links.
- Edit `app/globals.css` for typography, spacing, colors, and motion.
- Replace the placeholder art in the `moments` section with your own photos if desired.
